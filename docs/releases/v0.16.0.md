SpaceView now accelerates repeat NTFS scans using a verified metadata cache and
the Windows change journal.

- Open the same folder/drive again or click **Rescan**. Changed folders receive
  fresh reads, while validated unchanged branches are reused.
- Volume, folder, journal and security identities are checked. Missing history,
  permission changes, unreadable journals and corrupt caches trigger full scans.
- File sizes, timestamps and identities receive current metadata checks along
  the cached plan, including repeated writes through open or timestamp-only handles.
- Hardlinks receive coverage, including writes through aliases outside the selected folder.
- Right-click Rescan and choose **Full scan** to force ordinary traversal.
- Caches persist across launches and stay within a bounded disk budget.

The gauntlet compares cached results with fresh scans after filesystem changes
and tests native Rescan UI plus reuse from another process.
Rescans still read current file metadata; their speedup depends on directory
shape and disk activity.

Portable Windows build: download `spaceview.exe` and run it.
`SHA256SUMS.txt` contains the binary checksum.

The [website](https://tront.xyz/spaceview/) now shows v0.16.0 native screenshots,
verified rescan details and direct download links for the latest Windows EXE.
