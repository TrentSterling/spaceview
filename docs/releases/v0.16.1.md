Fixes the cold-scan slowdown and flashing live previews introduced in v0.16.0.

- Cold NTFS scans obtain file IDs with bulk directory metadata. They no longer
  open every file for read-data access just to populate the rescan cache.
- Each bounded live preview fills its visible detail before the frame is drawn,
  avoiding the brief collapse after every snapshot update.
- A global, size-weighted preview budget preserves completed-folder detail when
  the active scan moves deeper into a different branch.
- Cached rescans retain current metadata checks and conservative fallback.
- The gauntlet now exercises the actual cache-enabled scanner, compares scan
  throughput with and without previews, and checks every native live frame for
  collapsed visible detail.

Portable Windows build: download `spaceview.exe` and run it. The accompanying
`SHA256SUMS.txt` contains the executable checksum.
