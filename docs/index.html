How It Works

Squarified Treemaps

The classic treemap algorithm splits a rectangle into sub-rectangles proportional to file sizes. The "squarified" variant optimizes the aspect ratios so you get fat squares instead of thin slivers - much easier to read and click. Each depth level nests inside its parent, so the spatial hierarchy matches your actual folder structure.

Fresh Results on Rescan

After a complete NTFS scan, SpaceView saves a compact traversal plan. On the next scan, it checks the Windows change journal and reads current file identities, sizes and timestamps before publishing the result. If the cache cannot be verified, it scans normally. Right-click Rescan to choose a Full scan at any time.

Native Rescan test: the folder structure was reused and all 2,003 files received current metadata checks. Scan times depend on your disk and folder structure.
